CD-Tag comes with LAME 3.100 and FLAC 1.5.0 (in bin\Encoders).

To use another version instead, put it here:

  mp3\lame.exe    (and lame_enc.dll if your build has one)
  flac\flac.exe   (and libFLAC.dll if your build needs it)

These are used instead of the built-in encoders. A path chosen in
Tools > Options > Encoders wins over both.
